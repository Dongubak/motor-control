## 1. 현재 테스트 환경 — `homing_test.py`

### 환경 구성

```
슬레이브 0 (Z축): 하단 리미트 스위치(POT/DI1) 장착
                  → 하드웨어 Homing Mode(6) 수행
슬레이브 1 (Z축): 리미트 스위치 없음
                  → CSV Mode(9) 정지 대기 → 소프트웨어 원점 설정
```

### 동작 방식

1. 슬레이브 0: CiA 402 Homing Mode(6)로 정방향(CCW, 아래↓) 탐색 → POT 리미트 감지 후 원점 확정
2. 슬레이브 1: Homing 중 현재 위치 유지 (이동하지 않음)
3. 슬레이브 0 완료 후 → 양쪽 모터에 `set_origin()` 호출

### 실행 전 필수 준비

```
[ ] 슬레이브 1을 수동으로 슬레이브 0과 동일한 물리적 높이에 위치시킬 것
    (Homing 시작 후에는 이동하지 않으므로, 시작 위치가 소프트웨어 원점이 됨)
[ ] 슬레이브 0 하단 리미트 스위치 배선 확인
    NO  → Drive Pin 6 (+24V)
    COM → Drive Pin 11 (DI1/POT)
[ ] Z축 이동 경로 전 구간 장애물 없음 확인
[ ] 비상정지 스위치 위치 파악
```

### 실행

```bash
# 관리자 권한 터미널에서
python homing_test.py
```

### 실행 흐름 예시

```
==============================================================
  Z축 Homing 테스트 [현재 테스트 환경 — 모터 2대]
  슬레이브 0: Z축, 리미트 스위치 O → 하드웨어 Homing
  슬레이브 1: Z축, 리미트 스위치 X → 소프트웨어 원점
==============================================================
...
[5단계] Homing 시작 전 안전 확인
  [슬레이브 0] 하드웨어 Homing 수행
  [슬레이브 1] 소프트웨어 원점 설정
    - Homing 시작 전 슬레이브 0과 동일한 물리적 높이에 수동으로 위치시킨 후 Enter

  [Enter] Homing 시작 / Ctrl+C 취소:

[6단계] 슬레이브 0 하드웨어 Homing 실행
  두 모터 동시 시작 ...
  [ 11.3s]  M0(HW):탐색중(pos=+8234567)  M1(SW):정지(pos=+8234100)
  [ 14.8s]  M0(HW):완료(pos=0)  M1(SW):정지(pos=+8234100)
[Homing] 완료! 경과: 14.8s

[7단계] 결과 처리
  M0(HW): 0 pulse  (드라이브 원점 확정)
  M1(SW): +8234100 pulse  (현재 위치 그대로)
```

### 완료 후 CSV 연동

```python
# EtherCATBusCSV.start() 후
motor0.set_origin()   # → Homing 완료 위치(드라이브 원점)가 소프트웨어 0mm
motor1.set_origin()   # → 슬레이브 1 현재 위치가 소프트웨어 0mm
                      #    (수동으로 슬레이브 0과 같은 높이에 있었다면 두 원점이 물리적으로 일치)
```

## 2. 현장 테스트 환경 — `homing_test_field.py`

### 환경 구성

```
슬레이브 0 (X축): CSV Mode(9) 유지, Homing 없음 — 현재 위치 대기
슬레이브 1 (Z축): 하단 리미트 스위치(POT/DI1) 장착 → 하드웨어 Homing Mode(6)
슬레이브 2 (Z축): 하단 리미트 스위치(POT/DI1) 장착 → 하드웨어 Homing Mode(6)
```

### 동작 방식

1. 슬레이브 1, 2: 동시에 CiA 402 Homing Mode(6) 수행
2. 슬레이브 0 (X축): Homing 중 현재 위치 유지
3. 두 Z축 모터 모두 bit12(Homing Attained) = 1이 되면 완료
4. 두 모터의 완료 시점 차이는 정상 (독립 탐색)

### 실행 전 필수 준비

```
[ ] 슬레이브 1 하단 리미트 스위치 배선 확인
    NO  → Drive Pin 6 (+24V),  COM → Drive Pin 11 (DI1/POT)
[ ] 슬레이브 2 하단 리미트 스위치 배선 확인  (동일 방법)
[ ] 상단 리미트 스위치(NOT, DI2, Pin 12) 양쪽 모두 배선 확인
[ ] Z축 이동 경로 전 구간 (갠트리 전체 폭) 장애물 없음 확인
[ ] 비상정지 스위치 위치 파악
```

### 실행

```bash
# 관리자 권한 터미널에서
python homing_test_field.py
```

### 실행 흐름 예시

```
==============================================================
  Z축 Homing 테스트 [현장 테스트 환경 — 모터 3대]
  슬레이브 0: X축, Homing 없음 (CSV 유지)
  슬레이브 [1, 2]: Z축, 리미트 스위치 O → 하드웨어 Homing 동시 수행
==============================================================
...
[6단계] 슬레이브 [1, 2] 동시 하드웨어 Homing 실행
  [ 13.2s]  M1:탐색중(pos=+12345678)  M2:탐색중(pos=+12345432)
  [ 15.1s]  M1:완료(pos=0)  M2:탐색중(pos=+8765)
  [ 15.9s]  M1:완료(pos=0)  M2:완료(pos=+12)
[Homing] 완료! 경과: 15.9s

  두 Z축 완료 위치 차이: 12 pulse  (양호)
```

> **두 모터 완료 위치 차이**: Index 펄스 위치 차이로 인해 0이 아닐 수 있음.
> 10,000 pulse(≈ 0.004mm) 이하면 정상. 이상 시 각 드라이브 Homing 파라미터 재확인.

### 완료 후 CSV 연동

```python
# EtherCATBusCSV.start() 후
motor1.set_origin()   # → Homing 완료 위치가 소프트웨어 0mm
motor2.set_origin()   # → Homing 완료 위치가 소프트웨어 0mm
# motor0 (X축)은 별도 원점 설정
```

## 3. 공통 설정값

두 파일 모두 상단의 상수를 동일하게 조정한다.

```python
ADAPTER          = r'\Device\NPF_{...}'   # EtherCAT 어댑터 경로
SEARCH_SPEED_RPM = 10    # 스위치 탐색 속도 (RPM) — 초기 테스트는 5 이하 권장
ZERO_SPEED_RPM   = 1     # Index 펄스 탐색 속도 (RPM)
HOMING_METHOD    = 2     # 2=POT+Index(권장), -6=HOME 스위치 대안
HOMING_TIMEOUT_S = 120.0 # Homing 최대 허용 시간
```

### 속도 → UU/s 변환표

| RPM | UU/s |
|-----|------|
| 1   | ≈ 279,620 |
| 5   | ≈ 1,398,101 |
| 10  | ≈ 2,796,202 |
| 30  | ≈ 8,388,608 |

## 4. 오류 대처

| 증상 | 원인 | 조치 |
|------|------|------|
| bit13 즉시 발생 | POT 배선 없음/단선 | DI1 배선 재확인 |
| bit13, 탐색 후 발생 | Index 펄스 미감지 | `HOMING_METHOD = -6` 변경 |
| 타임아웃 120s | POT 스위치 미도달 | 스위치 위치 확인, 탐색속도 증가 |
| 드라이브 Fault | 추종오차/과전류 | 속도 낮춤, Fault 코드 확인 |

---

## 5. 실행 시 공통 유의사항

1. **관리자 권한 필수**: pysoem은 로우레벨 네트워크 접근 필요
2. **단독 실행**: `motor_csv_main2.py` 등 다른 EtherCAT 프로세스와 동시 실행 불가
3. **탐색 속도 보수적 시작**: 처음 실행 시 `SEARCH_SPEED_RPM = 5` 이하로 낮춰 안전 확인 후 증가
4. **비상정지 준비**: 모터가 예상치 못한 방향으로 움직이면 즉시 비상정지
5. **Z축 방향 확인**: 정방향(CCW, 아래↓)으로 탐색하는 것이 정상. 위로 움직이면 비정상
